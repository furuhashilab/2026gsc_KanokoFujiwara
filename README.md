# ライブ遠征者の情報探索行動に関する調査とAI活用型Web GISの提案
2026年ゼミ論
# Abstruct（要旨）
近年、アイドルやアーティストをはじめとする音楽ライブでの遠征が一般的になっており、多くのファンが国内外問わず移動するようになった。しかし、このライブ遠征では、ライブ会場だけではなく、宿泊施設、交通機関、コインロッカー、地域の飲食店や観光地など、多様な情報を複数のサービスから収集する必要があり、計画に時間と手間がかかるという課題がある。本研究では、ライブ遠征経験者へのアンケート調査および既存サービスを通して課題を整理し、その結果をもとにAIを活用したライブ遠征支援マップを作成する。利用者が必要な情報を一元的に取得できる仕組みを検討し、ライブ遠征をより快適にするための遠征者の情報探索を支援する方法を考察する。
# Introduction（導入）
研究背景
近年、K-POPをはじめとする音楽ライブやコンサートでは、居住地から離れた会場へ足を運ぶ「ライブ遠征」が一般的になっている。ライブ遠征では、ライブチケットの購入だけではなく、宿泊施設の予約、交通手段の検討、会場周辺の飲食店やコインロッカーの検索、さらには観光計画まで、多くの情報収集が必要となる。
現在はGoogleマップやホテル予約サイト、乗換案内アプリなど様々なサービスが存在しているが、それぞれのサービスが独立しているため、利用者は複数のサービスを行き来しながら情報を収集しなければならない。そのため、情報探索に時間と手間がかかることが課題となっている。

研究目的
本研究では、ライブ遠征経験者へのアンケート調査を通して、遠征時にどのような情報を必要としているのか、またどのような点に不便さを感じているのかを明らかにする。
さらに、既存サービスの比較・分析を行い、その結果を踏まえて、AIを活用したライブ遠征支援Web GISを提案・試作する。Web GISによる位置情報の可視化と、AIによる利用者の条件に応じた情報の整理・提案を組み合わせることで、ライブ遠征時の情報探索を効率化し、利用者の意思決定を支援することを目的とする。
なお、本研究では試作対象地域をみずほPayPayドーム福岡周辺とし、利用者評価を通してシステムの有効性と今後の改善点を検討する。

主な調査項目

・利用したサービス
・困ったこと
・情報収集方法
・あったら便利だと思う機能
・AIへの期待
目的：利用者ニーズを把握する。

・Googleマップ
・Yahoo!乗換案内
・ホテル予約サイト
・コインロッカー検索サービス

・情報量
・操作性
・情報の一元化
・ライブ遠征への適合性
