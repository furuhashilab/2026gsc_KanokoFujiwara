# 位置情報を活用した外国語学習ミッションが街の探索行動に与える影響の研究
### ― 街歩き型Web GISの試作と韓国語学習を事例とした比較分析 ―

**藤原かのこ｜青山学院大学 地球社会共生学部・古橋研究室｜2026年度ゼミ論**  


> **研究の問い：** 街の各地点に外国語学習ミッションを配置すると、通常の街歩きに比べて、訪問する場所や探索範囲、街への関心にどのような違いが生まれるのか。


## Abstract（要旨）
外国語学習には教室や教材だけでなく、日常生活の場所や行動と結びつけた学習方法がある。位置情報を用いた語学学習や探索型ゲームについても研究が行われている。本研究では、外国語の学習効果だけでなく、**学習ミッションが街を探索する動機となるか**に注目する。駅、カフェ、公園などに韓国語の単語や会話表現のミッションを設定し、参加者が地図上で地点を選び、現地を訪れて学べるWeb GISを試作する。通常の街歩きとミッション付きの街歩きを比較し、訪問地点数、移動経路、探索範囲および街への関心を分析する。また、外国語学習への意欲も副次的に調べる。結果を踏まえ、街歩きを通じた外国語学習の可能性と、位置情報に基づく体験設計について考察する。

## 1. Introduction（序論）

### 1.1 研究背景
私は外国語学習と街歩き・旅行に興味がある。街を歩いていると、駅、カフェ、公園、商店などで様々な表現が実際に使われる場面を想像できる。このような身近な場所と外国語を結びつければ、勉強のために出かけたり、普段は訪れない場所を発見したりするきっかけになるのではないかと考えた。

一方で、位置情報を利用した外国語学習アプリや、屋外の地点を巡って言語課題に取り組む研究は既に存在する。本研究では「GPSで単語を表示できる」こと自体を新規性とはせず、**地点ごとの外国語ミッションの存在によって、訪問先の選択や探索行動がどのように変わるか**を検証対象とする。

### 1.2 研究目的
場所に関連する外国語学習ミッションを提供する街歩き型Web GISを試作し、ミッションの有無による訪問地点・移動経路・探索意欲の違いを明らかにする。学習への楽しさや意欲についても補助的に評価する。

### 1.3 Research Questions
- **RQ1：** 外国語学習ミッション付きの街歩きでは、通常の街歩きと比べて訪問地点数、訪問先の種類、移動経路や探索範囲に違いが生じるか。
- **RQ2：** ミッションは、新しい場所を訪問したいという意欲や地域への関心にどのような影響を与えるか。
- **RQ3（副次的）：** 場所に結びついた韓国語ミッションを体験すると、外国語学習への楽しさや継続意欲はどう変わるか。

### 1.4 先行研究・既存の取り組み
| 研究・事例 | 主な取り組み | 本研究との重なり・差異 |
|---|---|---|
| **MiniHongo**（Tran et al., 2023） | 現在地・活動状況に関連した日本語の語彙学習支援 | 場所に関連する学習という点が共通。本研究は探索行動を主な評価対象にする |
| **Explorez / VdeUVic**（Perry, 2021） | キャンパスを巡るフランス語のクエスト型学習 | 探索型の仕組みが既に存在するため、「自分で場所を巡る」だけでは差別化できない |
| **Location-Based Games for Language Learning: A Scoping Review**（Richardson & Matthews, 2025） | 位置情報ゲームによる言語学習研究のレビュー | 研究デザイン・評価の考え方を参考にし、行動の空間的な比較を検討する |

**本研究で検証したい差異：** 外国語学習ミッションが、街の訪問先選択・移動経路・探索範囲に与える影響をGISで記録・分析すること。**ただし、先行研究を網羅的に確認した段階ではないため、独自性は現時点での仮説である。**

## 2. Methods（研究方法・計画）

### 2.1 対象地域と学習内容
初期の試作地域は、青山学院大学相模原キャンパス周辺など徒歩で調査できるエリアを候補とする。対象言語は**初級韓国語**とし、まずは駅・公園・カフェ・商店など5〜10地点を想定する。場所と学習内容を関連づけ、例えば駅では道案内、カフェでは注文、公園では周囲のものを説明する表現を扱う。

具体的な施設・通行可能な範囲は現地確認後に確定する。施設への入店や購入を参加条件にはしない。

### 2.2 Web GISの試作
- **MapLibre GL JS：** 地図上で学習スポットを表示する
- **OpenStreetMap等：** 駅・公園・店舗などの位置情報を活用する（利用規約・出典表記を遵守）
- **ブラウザのGeolocation API：** 本人の許可を得た場合のみ現在地を利用する
- **GeoJSON等：** 学習地点・訪問地点・経路などのデータ整理を検討する

**最小限の機能（PoC）：** 地図で学習地点を見る → 行きたい地点を自分で選ぶ → 現地で韓国語ミッションに取り組む → 訪問・達成記録を振り返る。

### 2.3 比較実験（予定）
同じ調査エリアで、次の条件を比較する。

- **A：通常の街歩き**：地図を使って一定時間自由に散歩する。
- **B：韓国語ミッション付き街歩き**：同じエリアで、地図の学習地点を選び、現地でミッションに取り組む。

参加者の地域への訪問経験、韓国語学習経験、歩行時間などを可能な限り揃える。サンプル数、実施場所、割り当て方法は教員と相談する。

**実験上の限界：** AとBの2条件では、行動の差が「ミッションの存在」によるものか「外国語によるもの」かを切り分けられない。韓国語固有の影響まで調べる場合には、**日本語ミッション付き街歩き**を加えた3条件の比較を検討する。

### 2.4 評価項目
| 観点 | 評価指標（予定） |
|---|---|
| 探索行動 | 訪問地点数、訪問地点の種類、移動距離、探索範囲 |
| 経路選択 | 訪問順序、移動経路、寄り道の傾向 |
| 地域への関心 | 新しい場所への訪問意欲、気づき・発見の自由記述 |
| 語学への関心 | 学習の楽しさ、継続意欲、学習内容の印象 |
| システム評価 | 操作性、使いにくかった点、改善要望 |

「普段訪れない場所」を判断するため、事前アンケートで対象地域への訪問経験も確認する。歩行時間・天候・端末精度などが結果に与える影響に注意する。

### 2.5 研究倫理と安全対策
移動ログ等の取得は説明と本人の同意に基づき、必要最小限の範囲で扱う。公開する結果は個人が特定されないように集計・匿名化する。歩行中の画面操作を避け、立ち止まってミッションに取り組む仕様とする。

## 3. Results（結果：今後の分析予定）

今後、条件A・Bの訪問地点や経路を地図で可視化し、探索範囲やアンケート結果の違いを比較する予定である。

## 4. Discussion（考察予定）
ミッション付き街歩きが訪問行動や地域への関心に関係するかを検討する。結果が変わらなかった場合も、その理由を分析する。また、ゲーム要素と言語要素の交絡、初級者の習熟度、地点配置やGPS誤差などの制約も考察する。

## 5. Expected Contributions（期待される成果）
- 韓国語ミッションを配置した街歩き型Web GISの試作品
- ミッションの有無による探索行動を比較した基礎的なデータ
- 学習地点の配置と街歩き体験の設計に関する知見
